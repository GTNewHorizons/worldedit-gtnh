# `//toggleplace`

Switch where things are placed.

Commands such as [//sphere](sphere.md) and [//paste](paste.md) work from your position. This switches them to work from position 1 of your selection, and back.

## Usage

```
//toggleplace
```

Also typed: `/toggleplace`

## Examples

| Command | What it does |
|---|---|
| `//toggleplace` | Switch the placement position. |

None needed.
