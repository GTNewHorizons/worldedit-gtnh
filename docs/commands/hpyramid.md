# `//hpyramid`

Generate a hollow pyramid.

The same as [//pyramid](pyramid.md) with `-h`.

## Usage

```
//hpyramid <pattern> <size>
```

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to build with. |
| `size` | The height of the pyramid. At least 1. |

## Examples

| Command | What it does |
|---|---|
| `//hpyramid sandstone 15` | A hollow pyramid. |
