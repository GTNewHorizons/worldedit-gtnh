# `/worldedit`

Commands about WorldEdit itself.

You can also type `/we`.

## Usage

```
/worldedit version
/worldedit reload
/worldedit reloadmappings
/worldedit cui
/worldedit tz <timezone>
/worldedit help [<command>]
```

Also typed: `/we`

## Commands

- [`/worldedit version`](worldedit-version.md): Show the version.
- [`/worldedit reload`](worldedit-reload.md): Reload the configuration.
- [`/worldedit reloadmappings`](worldedit-reloadmappings.md): Reload the rotation mappings.
- [`/worldedit cui`](worldedit-cui.md): Complete the handshake with the client mod.
- [`/worldedit tz`](worldedit-tz.md): Set your timezone.
- [`/worldedit help`](worldedit-help.md): Show the commands and how to use them.
