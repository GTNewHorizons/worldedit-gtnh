# `//removeabove`

Remove the blocks above you.

## Usage

```
//removeabove [<size> [<height>]]
```

## Arguments

| Argument | Meaning |
|---|---|
| `size` | The radius of the column. 1 by default. |
| `height` | How high to go. By default, to the top of the world. |

## Examples

| Command | What it does |
|---|---|
| `//removeabove 5` | Clear a column above you. |
