# `//schematic save`

Save your clipboard to a schematic.

Also typed `//save`. Rotations and flips of the clipboard are saved too.

## Usage

```
//schematic save <filename-or-format> [<filename>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `filename-or-format` | With one word, the file name. With two, the [format](schematic-formats.md). |
| `filename` | The file name, when you gave a format. |

## Examples

| Command | What it does |
|---|---|
| `//schem save house` | Save `house.schematic`. |
