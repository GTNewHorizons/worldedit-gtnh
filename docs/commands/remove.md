# `/remove`

Remove entities of a type around you.

## Usage

```
/remove <type> <radius>
```

Also typed: `/rem`, `/rement`

## Arguments

| Argument | Meaning |
|---|---|
| `type` | One of `all`, `projectiles` (or `arrows`), `items` (or `drops`), `fallingblocks`, `paintings` (or `art`), `itemframes`, `boats`, `minecarts` (or `carts`), `tnt` or `xp`. |
| `radius` | How far to go. -1 means all loaded chunks. |

## Examples

| Command | What it does |
|---|---|
| `/remove items 20` | Clear dropped items. |
| `/remove all -1` | Remove all of these everywhere it is loaded. |
