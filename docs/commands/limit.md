# `//limit`

Change how many blocks one edit may change.

The server can set a maximum for this.

## Usage

```
//limit <limit>
```

## Arguments

| Argument | Meaning |
|---|---|
| `limit` | The number of blocks. -1 goes back to the default. |

## Examples

| Command | What it does |
|---|---|
| `//limit 100000` | Allow bigger edits. |
| `//limit -1` | Back to the default. |

## Permission

`worldedit.limit`
