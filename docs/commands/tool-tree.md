# `//tool tree`

Bind the tree tool.

Clicking the ground grows a tree.

## Usage

```
//tool tree [<type>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `type` | The [tree type](../trees.md). Oak by default. |

## Examples

| Command | What it does |
|---|---|
| `//tool tree birch` | Plant birch trees. |
