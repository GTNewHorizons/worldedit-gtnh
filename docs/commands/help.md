# `//help`

Show the commands and how to use them.

It reads the real commands, so it always shows what can be typed. The slashes are optional, and a number at the end is the page.

## Usage

```
//help [<command>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `command` | A command, with subcommands if it has them, optionally followed by a page. |

## Examples

| Command | What it does |
|---|---|
| `//help` | List the commands. |
| `//help 2` | The second page. |
| `//help brush sphere` | How to use the sphere brush. |
