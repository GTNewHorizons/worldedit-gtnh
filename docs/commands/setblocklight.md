# `//setblocklight`

Set the block light in your selection.

## Usage

```
//setblocklight <level>
```

Also typed: `//setlight`

## Arguments

| Argument | Meaning |
|---|---|
| `level` | The light level, from 0 to 15. |

## Examples

| Command | What it does |
|---|---|
| `//setblocklight 15` | Light up the selection. |
