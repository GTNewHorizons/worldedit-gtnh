# `//tool lrbuild`

Bind the long range building tool.

Place and remove blocks at a distance.

## Usage

```
//tool lrbuild <leftclick> <rightclick>
```

## Arguments

| Argument | Meaning |
|---|---|
| `leftclick` | The [block](../patterns.md#blocks) that left click places. Use `air` to remove blocks. |
| `rightclick` | The [block](../patterns.md#blocks) that right click places. |

## Examples

| Command | What it does |
|---|---|
| `//tool lrbuild air stone` | Left click removes, right click builds. |
