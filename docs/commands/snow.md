# `//snow`

Cover the area around you in snow.

## Usage

```
//snow [<radius>]
```

Also typed: `/snow`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | How far to go. 10 by default. |

## Examples

| Command | What it does |
|---|---|
| `//snow 30` | Let it snow. |

## Permission

`worldedit.snow`
