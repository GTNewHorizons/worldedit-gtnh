# `/worldedit help`

Show the commands and how to use them.

The same as [//help](help.md).

## Usage

```
/worldedit help [<command>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `command` | A command, with subcommands if it has them, optionally followed by a page. |

## Examples

| Command | What it does |
|---|---|
| `/we help` | List the commands. |
