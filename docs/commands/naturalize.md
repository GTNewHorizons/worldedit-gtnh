# `//naturalize`

Make terrain look natural.

Replaces the top of the terrain with three layers of dirt with grass on top, and stone below.

## Usage

```
//naturalize
```

## Examples

| Command | What it does |
|---|---|
| `//naturalize` | Turn a stone hill into a natural one. |

## Permission

`worldedit.region.naturalize`
