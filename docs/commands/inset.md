# `//inset`

Shrink your selection from every direction.

## Usage

```
//inset [-hv] <amount>
```

## Arguments

| Argument | Meaning |
|---|---|
| `amount` | How many blocks to shrink on each side. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-h` | Only shrink sideways. |
| `-v` | Only shrink up and down. |

## Examples

| Command | What it does |
|---|---|
| `//inset 1` | Shrink by 1 block on all sides. |
