# `//schematic delete`

Delete a saved schematic.

This can not be undone.

## Usage

```
//schematic delete <filename>
```

Also typed: `//schematic d`

## Arguments

| Argument | Meaning |
|---|---|
| `filename` | The file name. |

## Examples

| Command | What it does |
|---|---|
| `//schem delete house` | Delete `house.schematic`. |
