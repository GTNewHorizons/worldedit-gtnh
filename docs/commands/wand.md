# `//wand`

Get the selection wand.

Gives you the wand item, a wooden axe unless the server changed it. Left click selects position 1, right click selects position 2.

## Usage

```
//wand
```

## Examples

| Command | What it does |
|---|---|
| `//wand` | Get the wand. |

## Permission

`worldedit.wand`
