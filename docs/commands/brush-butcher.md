# `//brush butcher`

Kill mobs where you click.

By default this only kills hostile mobs.

## Usage

```
//brush butcher [-plangbtfr] [<radius>]
```

Also typed: `//brush kill`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | The radius. 5 by default. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-p` | Also kill pets. |
| `-n` | Also kill NPCs. |
| `-g` | Also kill golems. |
| `-a` | Also kill animals. |
| `-b` | Also kill ambient mobs such as bats. |
| `-t` | Also kill mobs with a name tag. |
| `-f` | All of the above. |
| `-r` | Also destroy armor stands. |
| `-l` | Does nothing at the moment. |

## Examples

| Command | What it does |
|---|---|
| `//br butcher 10` | Kill hostile mobs at a distance. |
