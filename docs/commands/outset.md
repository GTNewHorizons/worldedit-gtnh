# `//outset`

Grow your selection in every direction.

## Usage

```
//outset [-hv] <amount>
```

## Arguments

| Argument | Meaning |
|---|---|
| `amount` | How many blocks to grow on each side. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-h` | Only grow sideways. |
| `-v` | Only grow up and down. |

## Examples

| Command | What it does |
|---|---|
| `//outset 3` | Grow by 3 blocks on all sides. |
| `//outset -h 3` | Grow by 3 blocks on the four sides only. |

## Permission

`worldedit.selection.outset`
