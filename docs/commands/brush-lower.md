# `/brush lower`

Lower terrain by one block where you click.

## Usage

```
/brush lower <shape> <size>
```

## Arguments

| Argument | Meaning |
|---|---|
| `shape` | `cuboid`, `sphere` or `cyl`. |
| `size` | The size of the shape. |

## Examples

| Command | What it does |
|---|---|
| `/br lower sphere 5` | Dig out a valley. |

## Permission

`worldedit.brush.lower`
