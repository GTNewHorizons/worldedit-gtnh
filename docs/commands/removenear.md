# `//removenear`

Remove a type of block around you.

## Usage

```
//removenear <block> [<size>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `block` | The [block](../patterns.md#blocks) to remove. |
| `size` | How far to go. 50 by default. |

## Examples

| Command | What it does |
|---|---|
| `//removenear torch 20` | Remove the torches nearby. |
