# `//thaw`

Remove the snow around you.

## Usage

```
//thaw [<radius>]
```

Also typed: `/thaw`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | How far to go. 10 by default. |

## Examples

| Command | What it does |
|---|---|
| `//thaw 30` | Melt the snow. |
