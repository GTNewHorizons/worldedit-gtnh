# `//fillr`

Fill a hole completely.

Like [//fill](fill.md), but follows the hole wherever it goes, also around corners.

## Usage

```
//fillr <block> <radius> [<depth>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `block` | The [pattern](../patterns.md) to fill with. |
| `radius` | How far to fill sideways. |
| `depth` | How far to fill down. No limit by default. |

## Examples

| Command | What it does |
|---|---|
| `//fillr water 20` | Fill a cave lake. |

## Permission

`worldedit.fill.recursive`
