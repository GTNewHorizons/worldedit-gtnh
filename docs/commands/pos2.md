# `//pos2`

Set the second corner of your selection.

Sets position 2 to the block you are standing in, or to the coordinates you type. This is the same as right clicking a block with the wand.

## Usage

```
//pos2 [<coordinates>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `coordinates` | The position as `x,y,z` or `x y z`. `~` is where you stand, and `~5` or `~-3` is that far from it. |

## Examples

| Command | What it does |
|---|---|
| `//pos2` | Use the block you stand in. |
| `//pos2 120,80,-180` | Use exact coordinates. |
| `//pos2 ~-10 ~ ~-10` | Use the block 10 west and 10 north of where you stand. |
| `//pos2 ~,~5,~` | Use the block 5 above where you stand. |
