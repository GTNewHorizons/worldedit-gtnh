# `/range`

Change how far the brush in your hand reaches.

## Usage

```
/range <range>
```

## Arguments

| Argument | Meaning |
|---|---|
| `range` | The distance in blocks. |

## Examples

| Command | What it does |
|---|---|
| `/range 50` | Reach 50 blocks. |

## Permission

`worldedit.brush.options.range`
