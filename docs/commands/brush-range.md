# `//brush range`

Change how far the brush in your hand reaches.

## Usage

```
//brush range <range>
```

## Arguments

| Argument | Meaning |
|---|---|
| `range` | The distance in blocks. |

## Examples

| Command | What it does |
|---|---|
| `//brush range 50` | Reach 50 blocks. |
