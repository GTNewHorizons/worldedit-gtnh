# `/worldedit tz`

Set your timezone.

Used for reading the dates of [snapshots](snapshot.md).

## Usage

```
/worldedit tz <timezone>
```

## Arguments

| Argument | Meaning |
|---|---|
| `timezone` | A timezone name, like `Europe/Paris` or `UTC`. |

## Examples

| Command | What it does |
|---|---|
| `/we tz UTC` | Use UTC. |
