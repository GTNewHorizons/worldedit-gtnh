# `/size`

Change the size of the brush in your hand.

Typed with one slash. The double slash `//size` is [something else](size.md).

## Usage

```
/size <radius>
```

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | The radius. The server sets a maximum. |

## Examples

| Command | What it does |
|---|---|
| `/size 8` | Use a bigger brush. |
