# `//brush raise`

Raise terrain by one block where you click.

## Usage

```
//brush raise <shape> <size>
```

## Arguments

| Argument | Meaning |
|---|---|
| `shape` | `cuboid`, `sphere` or `cyl`. |
| `size` | The size of the shape. |

## Examples

| Command | What it does |
|---|---|
| `//br raise sphere 5` | Build up a hill. |
