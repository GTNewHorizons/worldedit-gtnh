# `//removebelow`

Remove the blocks below you.

## Usage

```
//removebelow [<size> [<height>]]
```

## Arguments

| Argument | Meaning |
|---|---|
| `size` | The radius of the column. 1 by default. |
| `height` | How deep to go. By default, to the bottom of the world. |

## Examples

| Command | What it does |
|---|---|
| `//removebelow 5` | Dig a shaft. |
