# `/snapshot`

Choose a backup to restore from.

Snapshots are backups of the world, which the server has to be set up for. Choose one with these commands, then bring back your selection from it with [/restore](restore.md). You can also type `//snap`.

## Usage

```
/snapshot list [<num>]
/snapshot use <snapshot>
/snapshot sel <index>
/snapshot before <date>
/snapshot after <date>
```

Also typed: `/snap`

## Commands

- [`/snapshot list`](snapshot-list.md): List the available snapshots.
- [`/snapshot use`](snapshot-use.md): Choose a snapshot by name.
- [`/snapshot sel`](snapshot-sel.md): Choose a snapshot by its number in the list.
- [`/snapshot before`](snapshot-before.md): Choose the last snapshot before a date.
- [`/snapshot after`](snapshot-after.md): Choose the first snapshot after a date.

## Permission

None needed.
