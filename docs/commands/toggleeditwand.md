# `/toggleeditwand`

Turn the wand function on or off.

While it is off, the wand item acts like a normal item, so you can use the axe without changing your selection.

## Usage

```
/toggleeditwand
```

## Examples

| Command | What it does |
|---|---|
| `/toggleeditwand` | Switch between on and off. |
