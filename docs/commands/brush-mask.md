# `//brush mask`

Limit the brush in your hand to a mask.

The brush only changes blocks that match. Use it without a mask to turn it off.

## Usage

```
//brush mask [<mask>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `mask` | The [mask](../masks.md). Put it in quotes if it has spaces. |

## Examples

| Command | What it does |
|---|---|
| `//brush mask grass` | Only paint over grass. |
| `//brush mask` | Turn it off. |
