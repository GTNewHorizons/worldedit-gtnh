# `//drain`

Remove water and lava around you.

Removes the connected pool.

## Usage

```
//drain <radius>
```

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | How far to go. |

## Examples

| Command | What it does |
|---|---|
| `//drain 20` | Drain a lake. |

## Permission

`worldedit.drain`
