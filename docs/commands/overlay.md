# `//overlay`

Put a layer on top of the blocks in your selection.

## Usage

```
//overlay <pattern>
```

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to place. |

## Examples

| Command | What it does |
|---|---|
| `//overlay grass` | Put grass on top of everything. |

## Permission

`worldedit.region.overlay`
