# `//walls`

Build the four sides of your selection.

Leaves the top and the bottom alone. To include them, use [//faces](faces.md).

## Usage

```
//walls <pattern>
```

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to build with. |

## Examples

| Command | What it does |
|---|---|
| `//walls stonebrick` | Build a room's walls. |

## Permission

`worldedit.region.walls`
