# `//gmask`

Limit all your edits to a mask.

From now on, edits only change blocks that match. Use it without a mask to turn it off.

## Usage

```
//gmask [<mask>]
```

Also typed: `/gmask`

## Arguments

| Argument | Meaning |
|---|---|
| `mask` | The [mask](../masks.md). Put it in quotes if it has spaces. |

## Examples

| Command | What it does |
|---|---|
| `//gmask !air` | Only change blocks that are not air. |
| `//gmask` | Turn it off. |
