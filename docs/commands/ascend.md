# `/ascend`

Go up a floor.

## Usage

```
/ascend [<levels>]
```

Also typed: `/asc`

## Arguments

| Argument | Meaning |
|---|---|
| `levels` | How many floors. 1 by default. |

## Examples

| Command | What it does |
|---|---|
| `/ascend 2` | Go up two floors. |

## Permission

`worldedit.navigation.ascend`
