# `/jumpto`

Teleport to the block you are looking at.

Reaches up to 300 blocks.

## Usage

```
/jumpto
```

Also typed: `/j`

## Examples

| Command | What it does |
|---|---|
| `/jumpto` | Jump to where you look. |

## Permission

`worldedit.navigation.jumpto.command`
