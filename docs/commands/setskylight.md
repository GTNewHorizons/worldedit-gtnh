# `//setskylight`

Set the sky light in your selection.

## Usage

```
//setskylight <level>
```

## Arguments

| Argument | Meaning |
|---|---|
| `level` | The light level, from 0 to 15. |

## Examples

| Command | What it does |
|---|---|
| `//setskylight 15` | Set full sky light. |

## Permission

`worldedit.light.set`
