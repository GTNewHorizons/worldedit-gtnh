# `//paste`

Paste your clipboard.

Large pastes run over several ticks. You get a message once it is done.

## Usage

```
//paste [-sao]
```

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-a` | Skip air blocks. |
| `-o` | Paste at the position it was copied from, instead of relative to you. |
| `-s` | Select the pasted area afterwards. |

## Examples

| Command | What it does |
|---|---|
| `//paste` | Paste relative to you. |
| `//paste -as` | Paste without air and select the result. |
