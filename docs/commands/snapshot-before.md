# `//snapshot before`

Choose the last snapshot before a date.

## Usage

```
//snapshot before <date>
```

## Arguments

| Argument | Meaning |
|---|---|
| `date` | The date. It takes the rest of the line, and understands words like `yesterday`. |

## Examples

| Command | What it does |
|---|---|
| `//snap before yesterday` | The last one before yesterday. |
