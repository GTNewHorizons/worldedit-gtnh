# `//fixlava`

Make the lava around you still.

## Usage

```
//fixlava <radius>
```

Also typed: `/fixlava`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | How far to go. |

## Examples

| Command | What it does |
|---|---|
| `//fixlava 10` | Stop lava from flowing. |

## Permission

`worldedit.fixlava`
