# `/pumpkins`

Generate pumpkin patches around you.

## Usage

```
/pumpkins [<size>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `size` | How far from you to plant, in blocks. 10 by default. |

## Examples

| Command | What it does |
|---|---|
| `/pumpkins 15` | Scatter pumpkins. |

## Permission

`worldedit.generation.pumpkins`
