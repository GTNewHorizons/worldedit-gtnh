# `/snapshot sel`

Choose a snapshot by its number in the list.

## Usage

```
/snapshot sel <index>
```

## Arguments

| Argument | Meaning |
|---|---|
| `index` | The number from [/snap list](snapshot-list.md). |

## Examples

| Command | What it does |
|---|---|
| `/snap sel 2` | Use the second one. |
