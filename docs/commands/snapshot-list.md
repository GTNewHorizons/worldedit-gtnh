# `/snapshot list`

List the available snapshots.

## Usage

```
/snapshot list [<num>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `num` | How many to show, from 5 to 40. 5 by default. |

## Examples

| Command | What it does |
|---|---|
| `/snap list 20` | Show the last 20. |
