# `//hollow`

Hollow out what is in your selection.

Keeps a shell and clears the inside.

## Usage

```
//hollow [<thickness> [<pattern>]]
```

## Arguments

| Argument | Meaning |
|---|---|
| `thickness` | How thick the shell is, counted along the block grid. The default is 0, which leaves the thinnest shell. |
| `pattern` | The [pattern](../patterns.md) to fill the inside with. Air by default. |

## Examples

| Command | What it does |
|---|---|
| `//hollow` | Clear the inside. |
| `//hollow 2 water` | Keep a shell of 2 and fill the inside with water. |

## Permission

`worldedit.region.hollow`
