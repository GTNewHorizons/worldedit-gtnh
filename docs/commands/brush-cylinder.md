# `/brush cylinder`

Paint cylinders.

## Usage

```
/brush cylinder [-h] <pattern> [<radius> [<height>]]
```

Also typed: `/brush c`, `/brush cyl`

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to paint with. |
| `radius` | The radius. 2 by default. |
| `height` | The height. 1 by default. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-h` | Make them hollow. |

## Examples

| Command | What it does |
|---|---|
| `/br cylinder stone 3 5` | Paint stone pillars. |
