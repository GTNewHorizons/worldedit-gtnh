# `/cycler`

Bind the data value cycler tool.

Clicking a block changes its data value, which turns or recolors it.

## Usage

```
/cycler
```

## Examples

| Command | What it does |
|---|---|
| `/cycler` | Bind it to the item in your hand. |

## Permission

`worldedit.tool.data-cycler`
