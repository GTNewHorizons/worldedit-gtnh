# `//brush smooth`

Smooth the terrain where you click.

## Usage

```
//brush smooth [-n] [<size> [<iterations>]]
```

## Arguments

| Argument | Meaning |
|---|---|
| `size` | The radius. 2 by default. |
| `iterations` | How many times to smooth. 4 by default. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-n` | Only look at naturally occurring blocks. |

## Examples

| Command | What it does |
|---|---|
| `//br smooth 5` | Smooth with a bigger brush. |
