# `//fixwater`

Make the water around you still.

## Usage

```
//fixwater <radius>
```

Also typed: `/fixwater`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | How far to go. |

## Examples

| Command | What it does |
|---|---|
| `//fixwater 10` | Stop water from flowing. |

## Permission

`worldedit.fixwater`
