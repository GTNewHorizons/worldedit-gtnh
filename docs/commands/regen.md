# `//regen`

Regenerate your selection as the world generator made it.

Blocks outside the selection are kept, but mobs and other entities in the affected chunks are removed.

## Usage

```
//regen
```

## Examples

| Command | What it does |
|---|---|
| `//regen` | Restore the original terrain. |

## Permission

`worldedit.regen`
