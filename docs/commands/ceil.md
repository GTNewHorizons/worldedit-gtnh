# `/ceil`

Go up to the ceiling above you.

Puts a glass block under your feet if the server is set up to do so.

## Usage

```
/ceil [-fg] [<clearance>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `clearance` | How many blocks to stay below the ceiling. 0 by default. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-f` | Do not place glass, and fly instead. |
| `-g` | Always place glass. |

## Examples

| Command | What it does |
|---|---|
| `/ceil` | Go up to the ceiling. |

## Permission

`worldedit.navigation.ceiling`
