# `//ex`

Put out the fire around you.

## Usage

```
//ex [<radius>]
```

Also typed: `/ex`, `/ext`, `/extinguish`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | How far to go. 40 by default, or the maximum radius of the server if that is lower. |

## Examples

| Command | What it does |
|---|---|
| `//ex` | Extinguish nearby fire. |
