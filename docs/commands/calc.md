# `//calc`

Calculate a formula.

See [expressions](../expressions.md) for what you can use.

## Usage

```
//calc <expression>
```

Also typed: `//calculate`, `//eval`, `//evaluate`, `//solve`

## Arguments

| Argument | Meaning |
|---|---|
| `expression` | The formula. It takes the rest of the line, so it may hold spaces. |

## Examples

| Command | What it does |
|---|---|
| `//calc 2 + 2 * 8` | Prints 18. |
| `//calc sqrt(1024)` | Prints 32. |

## Permission

`worldedit.calc`
