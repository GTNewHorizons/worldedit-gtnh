# `/superpickaxe`

Choose how the super pickaxe works.

The super pickaxe breaks blocks instantly when you left click with a pickaxe. Turn it on and off with [//](superpickaxe-toggle.md). You can also type `//sp` or `//pickaxe`.

## Usage

```
/superpickaxe single
/superpickaxe area <radius>
/superpickaxe recursive <radius>
```

Also typed: `/pickaxe`, `/sp`

## Commands

- [`/superpickaxe single`](superpickaxe-single.md): Break one block at a time.
- [`/superpickaxe area`](superpickaxe-area.md): Break a cube of blocks.
- [`/superpickaxe recursive`](superpickaxe-recursive.md): Break all connected blocks of the same type.
- [`//`](superpickaxe-toggle.md): Turn the super pickaxe on or off.

## Permission

None needed.
