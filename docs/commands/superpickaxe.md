# `//superpickaxe`

Turn the super pickaxe on or off, or choose how it works.

The super pickaxe breaks blocks instantly when you left click with a pickaxe.

## Usage

```
//superpickaxe [<state>]
//superpickaxe [single]
//superpickaxe [area <radius>]
//superpickaxe [recursive <radius>]
```

Also typed: `//`, `//pickaxe`, `//sp`

## Arguments

| Argument | Meaning |
|---|---|
| `state` | `on` or `off`. Without it, it is switched. |

## Examples

| Command | What it does |
|---|---|
| `//` | Switch the super pickaxe. |
| `//superpickaxe off` | Make sure it is off. |

## Commands

- [`//superpickaxe single`](superpickaxe-single.md): Break one block at a time.
- [`//superpickaxe area`](superpickaxe-area.md): Break a cube of blocks.
- [`//superpickaxe recursive`](superpickaxe-recursive.md): Break all connected blocks of the same type.
