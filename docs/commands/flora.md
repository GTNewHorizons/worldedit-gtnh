# `//flora`

Grow grass and flowers in your selection.

## Usage

```
//flora [<density>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `density` | How dense, from 0 to 100. The default is 10. |

## Examples

| Command | What it does |
|---|---|
| `//flora 20` | Add plants to a field. |

## Permission

`worldedit.region.flora`
