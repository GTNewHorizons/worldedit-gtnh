# `/repl`

Bind the block replacer tool.

Right clicking a block replaces it. Left clicking takes the clicked block as the new material.

## Usage

```
/repl <block>
```

## Arguments

| Argument | Meaning |
|---|---|
| `block` | The [block](../patterns.md#blocks) to place. |

## Examples

| Command | What it does |
|---|---|
| `/repl stone` | Replace with stone. |
