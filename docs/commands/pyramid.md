# `//pyramid`

Generate a filled pyramid.

## Usage

```
//pyramid [-h] <pattern> <size>
```

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to build with. |
| `size` | The height of the pyramid. At least 1. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-h` | Make it hollow. |

## Examples

| Command | What it does |
|---|---|
| `//pyramid sandstone 15` | A sandstone pyramid. |
