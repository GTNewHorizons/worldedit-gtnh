# `//cancel`

Stop your running and queued edits.

Blocks that were already changed stay changed. Use [//undo](undo.md) to revert them.

## Usage

```
//cancel
```

## Examples

| Command | What it does |
|---|---|
| `//cancel` | Stop everything of yours. |

## Permission

`worldedit.cancel`
