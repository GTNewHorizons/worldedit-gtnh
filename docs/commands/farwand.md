# `/farwand`

Bind a selection wand that works at a distance.

Click to select the block you are looking at, however far away.

## Usage

```
/farwand
```

## Examples

| Command | What it does |
|---|---|
| `/farwand` | Bind it to the item in your hand. |

## Permission

`worldedit.tool.farwand`
