# `//tool`

Bind a function to the item in your hand.

Bind a tool to an item, then right click with that item to use it. See [//tool none](tool-none.md) to unbind, [//tool info](tool-info.md), [//tool tree](tool-tree.md), [//tool repl](tool-repl.md), [//tool cycler](tool-cycler.md), [//tool floodfill](tool-floodfill.md), [//tool deltree](tool-deltree.md), [//tool farwand](tool-farwand.md) and [//tool lrbuild](tool-lrbuild.md).

## Usage

```
//tool none
//tool info
//tool tree [<type>]
//tool repl <block>
//tool cycler
//tool floodfill <pattern> <range>
//tool deltree
//tool farwand
//tool lrbuild <leftclick> <rightclick>
```

Also typed: `//tool flood` for `//tool floodfill`

## Commands

- [`//tool none`](tool-none.md): Unbind the tool from the item in your hand.
- [`//tool info`](tool-info.md): Bind the block information tool.
- [`//tool tree`](tool-tree.md): Bind the tree tool.
- [`//tool repl`](tool-repl.md): Bind the block replacer tool.
- [`//tool cycler`](tool-cycler.md): Bind the data value cycler tool.
- [`//tool floodfill`](tool-floodfill.md): Bind the flood fill tool.
- [`//tool deltree`](tool-deltree.md): Bind the floating tree remover.
- [`//tool farwand`](tool-farwand.md): Bind a selection wand that works at a distance.
- [`//tool lrbuild`](tool-lrbuild.md): Bind the long range building tool.
