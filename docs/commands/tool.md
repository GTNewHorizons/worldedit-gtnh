# `/tool`

Bind a function to the item in your hand.

Each of these can also be typed without `tool`, so `//tool info` and `/info` are the same. Bind a tool to an item, then right click with that item to use it. See [/none](none.md) to unbind, [/info](info.md), [/tree](tree.md), [/repl](repl.md), [/cycler](cycler.md), [/floodfill](floodfill.md), [/deltree](deltree.md), [/farwand](farwand.md) and [/lrbuild](lrbuild.md).

## Usage

```
/tool none
/tool info
/tool tree [<type>]
/tool repl <block>
/tool cycler
/tool floodfill <pattern> <range>
/tool deltree
/tool farwand
/tool lrbuild <leftclick> <rightclick>
```
