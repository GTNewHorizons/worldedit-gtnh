# `//redo`

Redo what you undid.

Refused while an edit of yours is still running. Wait for it or use [//cancel](cancel.md).

## Usage

```
//redo [<times> [<player>]]
```

Also typed: `/redo`

## Arguments

| Argument | Meaning |
|---|---|
| `times` | How many edits to redo. 1 by default. |
| `player` | The player whose history to redo. This needs the extra permission `worldedit.history.redo.other`. |

## Examples

| Command | What it does |
|---|---|
| `//redo` | Redo one edit. |
