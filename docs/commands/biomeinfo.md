# `//biomeinfo`

Show the biomes in your selection.

## Usage

```
//biomeinfo [-pt]
```

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-p` | Use the block you are in instead. |
| `-t` | Use the block you are looking at instead. |

## Examples

| Command | What it does |
|---|---|
| `//biomeinfo` | The biomes in your selection. |
| `//biomeinfo -p` | The biome where you stand. |
