# `/schematic`

Save and load schematic files.

Schematics are stored in the schematics folder of the server, by default `config/worldedit/schematics`. You can also type `//schem`, and `//load` and `//save` are other names for loading and saving.

## Usage

```
/schematic load <filename-or-format> [<filename>]
/schematic save <filename-or-format> [<filename>]
/schematic delete <filename>
/schematic formats
/schematic list [-dn] [-p <page>]
```

Also typed: `/schem`

## Commands

- [`/schematic load`](schematic-load.md): Load a schematic into your clipboard.
- [`/schematic save`](schematic-save.md): Save your clipboard to a schematic.
- [`/schematic delete`](schematic-delete.md): Delete a saved schematic.
- [`/schematic formats`](schematic-formats.md): List the schematic formats.
- [`/schematic list`](schematic-list.md): List the saved schematics.
