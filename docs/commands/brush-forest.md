# `//brush forest`

Plant trees on the surfaces in a shape.

## Usage

```
//brush forest <shape> <size> <density> <tree>
```

## Arguments

| Argument | Meaning |
|---|---|
| `shape` | `cuboid`, `sphere` or `cyl`. |
| `size` | The size of the shape. |
| `density` | How dense, from 0 to 100. |
| `tree` | The [tree type](../trees.md). |

## Examples

| Command | What it does |
|---|---|
| `//br forest sphere 10 5 birch` | Paint a birch forest. |
