# `/snapshot after`

Choose the first snapshot after a date.

## Usage

```
/snapshot after <date>
```

## Arguments

| Argument | Meaning |
|---|---|
| `date` | The date. It takes the rest of the line, and understands words like `yesterday`. |

## Examples

| Command | What it does |
|---|---|
| `/snap after 2 days ago` | The first one in the last two days. |

## Permission

`worldedit.snapshots.restore`
