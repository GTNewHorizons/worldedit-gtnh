# `//hpos1`

Set position 1 to the block you are looking at.

Handy for corners you can not reach. It looks up to 300 blocks away.

## Usage

```
//hpos1
```

## Examples

| Command | What it does |
|---|---|
| `//hpos1` | Select the block in your crosshair as position 1. |

## Permission

`worldedit.selection.hpos`
