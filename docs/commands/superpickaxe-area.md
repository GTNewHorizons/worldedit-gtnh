# `/superpickaxe area`

Break a cube of blocks.

## Usage

```
/superpickaxe area <radius>
```

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | How far to go. The server sets a maximum. |

## Examples

| Command | What it does |
|---|---|
| `/sp area 3` | Break everything within 3 blocks. |

## Permission

`worldedit.superpickaxe.area`
