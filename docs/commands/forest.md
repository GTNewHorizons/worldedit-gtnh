# `//forest`

Grow a forest in your selection.

## Usage

```
//forest [<type> [<density>]]
```

## Arguments

| Argument | Meaning |
|---|---|
| `type` | The [tree type](../trees.md). Oak by default. |
| `density` | How dense, from 0 to 100. The default is 5. |

## Examples

| Command | What it does |
|---|---|
| `//forest` | Grow an oak forest. |
| `//forest birch 10` | Grow a denser birch forest. |
