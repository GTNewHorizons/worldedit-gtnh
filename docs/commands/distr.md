# `//distr`

List which blocks your selection is made of.

Shows every block type with its amount and percentage.

## Usage

```
//distr [-cd]
```

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-d` | Tell data values apart. |
| `-c` | Meant to use your clipboard, but this is not implemented and gives an error. |

## Examples

| Command | What it does |
|---|---|
| `//distr` | List block types. |
| `//distr -d` | List block types with their data values. |
