# `//set`

Fill your selection.

Large edits run over several ticks, so the server keeps running. You get a message once it is done.

## Usage

```
//set <pattern>
```

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to fill with. |

## Examples

| Command | What it does |
|---|---|
| `//set stone` | Fill with stone. |
| `//set 50%stone,50%dirt` | Fill with a mix of stone and dirt. |
| `//set air` | Clear the selection. |
