# `//forestgen`

Generate a forest around you.

## Usage

```
//forestgen [<size> [<type> [<density>]]]
```

## Arguments

| Argument | Meaning |
|---|---|
| `size` | How far from you to plant, in blocks. 10 by default. |
| `type` | The [tree type](../trees.md). Oak by default. |
| `density` | How dense, from 0 to 100. The default is 5. |

## Examples

| Command | What it does |
|---|---|
| `//forestgen 20 birch 10` | A dense birch forest. |
