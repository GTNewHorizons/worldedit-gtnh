# `//hpos2`

Set position 2 to the block you are looking at.

Handy for corners you can not reach. It looks up to 300 blocks away.

## Usage

```
//hpos2
```

## Examples

| Command | What it does |
|---|---|
| `//hpos2` | Select the block in your crosshair as position 2. |

## Permission

`worldedit.selection.hpos`
