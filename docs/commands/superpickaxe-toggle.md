# `//`

Turn the super pickaxe on or off.

This command is typed as just two slashes.

## Usage

```
// [<state>]
```

Also typed: `/,`

## Arguments

| Argument | Meaning |
|---|---|
| `state` | `on` or `off`. Without it, it is switched. |

## Examples

| Command | What it does |
|---|---|
| `//` | Switch the super pickaxe. |
| `// off` | Make sure it is off. |

## Permission

`worldedit.superpickaxe`
