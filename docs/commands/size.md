# `//size`

Show information about your selection.

Shows the selection type, its dimensions and how many blocks it holds.

## Usage

```
//size [-c]
```

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-c` | Show the size of your clipboard instead. |

## Examples

| Command | What it does |
|---|---|
| `//size` | Inspect the selection. |
| `//size -c` | Inspect the clipboard. |
