# `/descend`

Go down a floor.

## Usage

```
/descend [<levels>]
```

Also typed: `/desc`

## Arguments

| Argument | Meaning |
|---|---|
| `levels` | How many floors. 1 by default. |

## Examples

| Command | What it does |
|---|---|
| `/descend` | Go down one floor. |

## Permission

`worldedit.navigation.descend`
