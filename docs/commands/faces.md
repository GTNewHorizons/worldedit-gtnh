# `//faces`

Build all six sides of your selection.

Walls, floor and ceiling.

## Usage

```
//faces <pattern>
```

Also typed: `//outline`

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to build with. |

## Examples

| Command | What it does |
|---|---|
| `//faces glass` | Build a glass box. |

## Permission

`worldedit.region.faces`
