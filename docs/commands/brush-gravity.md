# `//brush gravity`

Make blocks fall where you click.

## Usage

```
//brush gravity [-h] [<radius>]
```

Also typed: `//brush grav`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | The radius. 5 by default. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-h` | Start from the top of the world, instead of from the clicked block plus the radius. |

## Examples

| Command | What it does |
|---|---|
| `//br gravity 8` | Drop floating blocks. |
