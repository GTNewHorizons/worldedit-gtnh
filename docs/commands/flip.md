# `//flip`

Mirror your clipboard.

Flips across the point where you stood when you copied.

## Usage

```
//flip [<direction>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `direction` | The [direction](../directions.md) to flip in. By default, the direction you are looking in. |

## Examples

| Command | What it does |
|---|---|
| `//flip` | Flip along where you look. |
| `//flip up` | Flip upside down. |
