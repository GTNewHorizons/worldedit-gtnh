# `//brush ex`

Put out fire where you click.

## Usage

```
//brush ex [<radius>]
```

Also typed: `//brush extinguish`

## Arguments

| Argument | Meaning |
|---|---|
| `radius` | The radius. 5 by default. |

## Examples

| Command | What it does |
|---|---|
| `//br ex 10` | A fire extinguisher. |
