# `//fast`

Turn fast mode on or off.

Fast mode skips some updates, which makes edits quicker but can leave wrong lighting. You may need to rejoin to see the changes.

## Usage

```
//fast [<state>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `state` | `on` or `off`. Without it, the mode is switched. |

## Examples

| Command | What it does |
|---|---|
| `//fast` | Switch fast mode. |
| `//fast off` | Make sure it is off. |
