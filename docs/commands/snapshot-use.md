# `//snapshot use`

Choose a snapshot by name.

## Usage

```
//snapshot use <snapshot>
```

## Arguments

| Argument | Meaning |
|---|---|
| `snapshot` | The name, or `latest` for the newest one. |

## Examples

| Command | What it does |
|---|---|
| `//snap use latest` | Use the newest. |
