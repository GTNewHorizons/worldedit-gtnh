# `/up`

Go straight up.

Puts a glass block under your feet if the server is set up to do so.

## Usage

```
/up [-fg] <distance>
```

## Arguments

| Argument | Meaning |
|---|---|
| `distance` | How many blocks to go up. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-f` | Do not place glass, and fly instead. |
| `-g` | Always place glass. |

## Examples

| Command | What it does |
|---|---|
| `/up 20` | Rise 20 blocks. |

## Permission

`worldedit.navigation.up`
