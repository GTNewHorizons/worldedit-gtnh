# `//rotate`

Rotate your clipboard.

Rotations add up, and the blocks are only changed when you paste. Positive angles turn clockwise. Use multiples of 90 degrees, other angles leave gaps.

## Usage

```
//rotate <y-axis> [<x-axis> [<z-axis>]]
```

## Arguments

| Argument | Meaning |
|---|---|
| `y-axis` | The degrees to turn around the vertical axis. This is the one you usually want. |
| `x-axis` | The degrees to turn around the x axis. |
| `z-axis` | The degrees to turn around the z axis. |

## Examples

| Command | What it does |
|---|---|
| `//rotate 90` | Turn a quarter clockwise. |
| `//rotate 0 180` | Turn upside down. |
