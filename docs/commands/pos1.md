# `//pos1`

Set the first corner of your selection.

Sets position 1 to the block you are standing in, or to the coordinates you type. This is the same as left clicking a block with the wand.

## Usage

```
//pos1 [<coordinates>]
```

## Arguments

| Argument | Meaning |
|---|---|
| `coordinates` | The position as `x,y,z`, without spaces. |

## Examples

| Command | What it does |
|---|---|
| `//pos1` | Use the block you stand in. |
| `//pos1 100,64,-200` | Use exact coordinates. |
