# `//searchitem`

Search for a block or item by name.

Shows at most 15 results. You can also search by item ID.

## Usage

```
//searchitem [-bi] <query>
```

Also typed: `//l`, `//search`, `/searchitem`

## Arguments

| Argument | Meaning |
|---|---|
| `query` | A part of the name, at least 3 letters, or an item ID. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-b` | Only search blocks. |
| `-i` | Only search items. |

## Examples

| Command | What it does |
|---|---|
| `//searchitem wool` | Find everything called wool. |
| `//searchitem -b 35` | Look up ID 35. |

## Permission

None needed.
