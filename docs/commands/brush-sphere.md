# `//brush sphere`

Paint spheres.

## Usage

```
//brush sphere [-h] <pattern> [<radius>]
```

Also typed: `//brush s`

## Arguments

| Argument | Meaning |
|---|---|
| `pattern` | The [pattern](../patterns.md) to paint with. |
| `radius` | The radius. 2 by default. |

## Flags

Flags go right after the command, before the arguments.

| Flag | Meaning |
|---|---|
| `-h` | Make them hollow. |

## Examples

| Command | What it does |
|---|---|
| `//br sphere stone 5` | Paint stone balls. |
