# Tree types

Used by [`//forest`](commands/forest.md), [`//forestgen`](commands/forestgen.md), the [`//tool tree`](commands/tool-tree.md) tool and the [forest brush](commands/brush-forest.md).

| Tree | Names you can type |
|---|---|
| Oak | `oak`, `tree`, `regular` |
| Large oak | `largeoak`, `bigoak`, `big`, `bigtree` |
| Spruce | `spruce`, `redwood`, `sequoia`, `sequoioideae` |
| Tall spruce | `tallspruce`, `bigspruce`, `tallredwood`, `tallsequoia` |
| Large spruce | `largespruce`, `megaredwood` |
| Random spruce | `randspruce`, `randredwood`, `randomredwood` |
| Birch | `birch`, `white`, `whitebark` |
| Tall birch | `tallbirch` |
| Random birch | `randbirch`, `randombirch` |
| Jungle | `jungle` |
| Small jungle | `shortjungle`, `smalljungle` |
| Random jungle | `randjungle`, `randomjungle` |
| Jungle bush | `junglebush`, `jungleshrub` |
| Red mushroom | `redmushroom`, `redgiantmushroom` |
| Brown mushroom | `brownmushroom`, `browngiantmushroom` |
| Random mushroom | `randmushroom`, `randommushroom` |
| Swamp | `swamp`, `swamptree` |
| Acacia | `acacia` |
| Dark oak | `darkoak` |
| Pine | `pine` |
| Random | `rand`, `random` |
