# Directions

Commands that move or grow something can take a direction.

| You type | It means |
|---|---|
| `north`, `south`, `east`, `west` | That compass direction |
| `up`, `down` | Straight up or down |
| `me` or `forward` | The direction you are looking in |
| `back` | Behind you |
| `left`, `right` | To your side |

Only the first letter usually matters, so `n` is enough for north and `u` for up.

Some commands take several directions separated by commas, for example [`//expand 5 north,east`](commands/expand.md).

Without a direction, commands use the way you are looking. This goes for [`//stack`](commands/stack.md), [`//move`](commands/move.md), [`//expand`](commands/expand.md), [`//contract`](commands/contract.md), [`//shift`](commands/shift.md) and [`//flip`](commands/flip.md).
